# 今天搓什么能赚钱

FF14 国服生产职业赚钱推荐：找出**材料在市场上就能买齐、材料成本远低于成品售价、最近真有人在买**的配方。
四个大区（陆行鸟 / 莫古力 / 猫小胖 / 豆豆柴）分别计算，每 6 小时自动更新。

## 怎么算的

- **售价**：最近 30 天成交价的中位数；如果现在有人挂得更低，按更低的算。能做高品质的按 HQ 成交算。
- **材料成本**：按“做 3 次”的量，从最便宜的挂单开始买够计算；挂单数量不够的配方直接排除。
- **单件利润**：售价扣 5% 市场税，再减材料成本。
- **销量**：每天平均卖出数量、最近一次成交时间。成交记录太少（30 天内不到 2 笔）的不算。
- 默认只显示“材料成本 ≤ 售价 10%、每天至少卖出 1 个”的配方，网页上可以调。

价格数据来自玩家共享的 [Universalis](https://universalis.app)，配方和物品数据来自
[ffxiv-datamining-cn](https://github.com/thewakingsands/ffxiv-datamining-cn)。
数据靠玩家上传，可能有延迟，下手前请在游戏里的市场板确认。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 网页 |
| `build_data.py` | 下载游戏数据、查价格、算利润，生成 `data/<大区>.js` |
| `.github/workflows/update.yml` | GitHub 自动任务：每 6 小时跑一次 `build_data.py` 并发布网页 |

本地运行：`python build_data.py`（四个大区约 15 分钟），然后双击 `index.html`。
